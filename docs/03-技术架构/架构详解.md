> 本文档是项目 SOT「技术怎么实现」。技术栈 / 模块拆分 / 依赖关系 / 关键技术决策。

> **本文档与项目规则的关系**：本文维护详细技术设计；Claude 的 `CLAUDE.md`、Codex 的有效 `AGENTS.override.md` / `AGENTS.md` 维护各自适用的行为约束与文档入口，沿显式引用读取资料，不假定入口一定保存完整架构。入口若保留技术摘要，应与本文一致。交付核对：Claude Code 调用 `/dev-delivery-check`，Codex 调用 `$dev-delivery-check`。

> **三处结构描述的职责分工**（避免改一处忘两处）：
>
> | 文档 | 职责 | 更新时机 |
> |---|---|---|
> | 项目适用规则文件或其明确引用的目录职责地图 | 每个目录放什么、如何组织 | 目录结构变化时 |
