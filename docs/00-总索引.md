# 项目文档总索引

本页是可信评测平台的工程文档入口。平台、SDK、插件、教学示例和上游文档站保留在同一仓库，按职责导航，不因整理目录而移动源码或改包名。

## 从任务找入口

| 当前任务 | 入口 |
|---|---|
| 理解工程结构、查开发命令 | [根 AGENTS.md](../AGENTS.md)、[开发细节](../DEVELOPMENT.md) |
| 修改后端或数据库 | [服务端](../src/phoenix/server/)、[数据库](../src/phoenix/db/)、[技术架构](03-技术架构/架构详解.md) |
| 修改网页 | [React 应用](../js/app/)、[前端开发说明](../js/app/README.md) |
| 修改或发布 SDK | [Python 包](../packages/)、[TypeScript 包](../js/packages/)、[JS workspace 说明](../js/DEVELOPMENT.md) |
| 维护工具插件 | [插件实现](../plugins/)、[共享技能](../.agents/skills/README.md) |
| 验证功能、执行评测 | [Python 测试](../tests/)、[UI 测试](../js/app/tests/)、[专项评测](../evals/) |
| 找接入示例 | [Python 示例](../examples/)、[JS 示例](../js/examples/)、[教程](../tutorials/)、[Java 示例](../java/examples/) |
| 使用源码 Docker + 本机 PostgreSQL 或 Compose 部署 | [统一部署指南](04-部署文档/部署指南.md#local-source-pg)；包含构建、启动与历史验证记录 |
| 查 Kubernetes 等其他部署方案 | [部署形态与边界](04-部署文档/部署指南.md)、[Helm](../helm/)、[Kustomize](../kustomize/) |

SDK 发布流程保留在 `.github/workflows/publish.yaml`、`typescript-packages-publish.yml` 等文件中；它们属于发布自动化，普通本地部署无需执行。插件市场入口位于根 `.claude-plugin/`、`.cursor-plugin/` 和 `.agents/plugins/`，与开发工具自身的项目配置分开维护。

## 交付一致性检查

按交付核验要求调用 `dev-delivery-check`，跨 9 份产物（5 段 reference + spec + plan + code + 项目规则文件）做对账。`dev-eod` 只提示检查，不自动执行。公共约定见 `~/Documents/Obsidian/dev-vault/VAULT.md`，两端完整调用见同一 Vault 的 `resources/日常操作指南.md`。

## 项目阶段

本项目当前阶段在项目根适用规则文件的「项目阶段」段声明（值为 `initialization` 或 `iteration`）：Claude 按其入口读取；Codex 由技能加载器选择有效 `AGENTS.override.md` / `AGENTS.md`，项目根兼容后备 `CLAUDE.md`。该字段影响 `dev-delivery-check` 的 SOT 优先级判断。
