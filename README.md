Arize Phoenix 是 Arize 的开源 AI 可观测平台，专为实验、评估和故障排查而设计。对于托管式生产工作流，Arize 还提供 [Arize AX](https://arize.com/products/ax/)。Phoenix 提供：

- [**_追踪_**](https://arize.com/docs/phoenix/tracing/llm-traces) - 使用基于 OpenTelemetry 的埋点追踪 LLM 应用的运行过程。
- [**_评估_**](https://arize.com/docs/phoenix/evaluation/llm-evals) - 使用 LLM 对响应和检索进行评估，衡量应用性能。
- [**_数据集_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets) - 创建带版本管理的示例数据集，用于实验、评估和微调。
- [**_实验_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets#experiments) - 追踪并评估提示词、LLM 和检索的变更。
- [**_Playground_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts)- 优化提示词、对比模型、调整参数，并重放已追踪的 LLM 调用。
- [**_提示词管理_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts/prompt-management)- 通过版本控制、标签和实验，系统地管理及测试提示词变更。
- [**_PXI (Phoenix Intelligence)_**](https://arize.com/docs/phoenix/pxi) - Phoenix 内置的 AI 工程 Agent，用于调试追踪、迭代提示词和操作产品。
- [**_远程 MCP 服务_**](https://arize.com/docs/phoenix/integrations/mcp#remote-mcp-server) - 将 Claude Code、Cursor 等 MCP 客户端直接连接至 Phoenix 实例的 `/mcp` 端点，查询追踪、数据集、实验等内容。

Phoenix 不依赖特定厂商或语言，开箱即支持主流框架（[OpenAI Agents SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai-agents-sdk)、[Claude Agent SDK](https://arize.com/docs/phoenix/integrations/python/claude-agent-sdk)、[LangGraph](https://arize.com/docs/phoenix/tracing/integrations-tracing/langchain)、[Vercel AI SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/vercel-ai-sdk)、[Mastra](https://arize.com/docs/phoenix/integrations/typescript/mastra)、[CrewAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/crewai)、[LlamaIndex](https://arize.com/docs/phoenix/tracing/integrations-tracing/llamaindex)、[DSPy](https://arize.com/docs/phoenix/tracing/integrations-tracing/dspy)）以及 LLM 提供方（[OpenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai)、[Anthropic](https://arize.com/docs/phoenix/tracing/integrations-tracing/anthropic)、[Google GenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/google-genai)、[Google ADK](https://arize.com/docs/phoenix/integrations/llm-providers/google-gen-ai/google-adk-tracing)、[AWS Bedrock](https://arize.com/docs/phoenix/tracing/integrations-tracing/bedrock)、[OpenRouter](https://arize.com/docs/phoenix/integrations/python/openrouter)、[LiteLLM](https://arize.com/docs/phoenix/tracing/integrations-tracing/litellm) 等）。有关自动埋点的详细信息，请参阅 [OpenInference](https://github.com/Arize-ai/openinference) 项目。

Phoenix 几乎可以在任何环境中运行，包括本地计算机、容器化部署和云端。请参阅[运行环境](https://arize.com/docs/phoenix/environments)，了解各个选项的操作步骤，或直接开始[追踪快速入门](https://arize.com/docs/phoenix/get-started/get-started-tracing)。

> [!NOTE]
> Phoenix 开源且支持自托管。对于托管平台，Arize 提供 [Arize AX](https://arize.com/products/ax/)；同一套 OpenTelemetry/OpenInference 埋点可同时用于两者。请参阅[完整对比](https://arize.com/docs/phoenix/resources/frequently-asked-questions/what-is-the-difference-between-phoenix-and-arize)。

## 本地运行

通过 `pip` 或 `conda` 安装即可获得功能完整的 Phoenix。有关所有安装和托管选项，请参阅[安装指南](https://arize.com/docs/phoenix)。

```shell
pip install arize-phoenix
phoenix serve
```

也可以使用 [`uvx`](https://docs.astral.sh/uv/) 免安装运行：

```shell
uvx arize-phoenix serve
```

<a id="trace-your-application"></a>

## 追踪应用

发送追踪最快的方式是让[编码 Agent](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents)（Claude Code、Codex、Cursor 等）为应用埋点。在项目目录中运行：

```shell
npx @arizeai/phoenix-cli setup
# 或者，已安装 Phoenix 时运行：px setup
```

设置流程会检测框架和 LLM 提供方，安装适合的 [OpenInference](https://github.com/Arize-ai/openinference) 埋点库，并配置追踪导出。如需在代码中配置，请参阅[追踪文档](https://arize.com/docs/phoenix/tracing/llm-traces)。

## 部署

Phoenix 容器镜像可从 [Docker Hub](https://hub.docker.com/r/arizephoenix/phoenix) 获取，并可通过 Docker 或使用 [Helm chart](https://github.com/Arize-ai/phoenix/tree/main/helm) 的 Kubernetes 进行部署。

有关 Docker Compose、Kubernetes/Helm 及其他部署选项，请参阅[自托管文档](https://arize.com/docs/phoenix/self-hosting)。

<a id="for-humans-and-coding-agents"></a>

## 面向开发者与编码 Agent

Phoenix 既支持开发者操作，也支持 AI 编码 Agent 驱动。以下三个入口可让 Agent（Claude Code、Codex、Cursor 等）使用追踪、数据集和实验：

- **[CLI](https://arize.com/docs/phoenix/sdk-api-reference/typescript/arizeai-phoenix-cli)** — `npx @arizeai/phoenix-cli` 可获取追踪、数据集和实验，并为应用埋点（`setup`），让 Agent 从终端获取上下文并执行操作。
- **[技能](https://docs.anthropic.com/en/docs/claude-code/skills)** — [`.agents/skills/`](.agents/skills/) 封装工作流，指导 Agent 使用 Phoenix 进行调试、评估和追踪。
- **[远程 MCP 服务](https://arize.com/docs/phoenix/integrations/mcp#remote-mcp-server)** — 将任意 MCP 客户端连接至实例的 `/mcp` 端点，直接查询 Phoenix。

有关设置和使用方法，请参阅[编码 Agent 文档](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents)。

| 技能                                              | 说明                                                                                                                |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [phoenix-cli](.agents/skills/phoenix-cli/)         | 使用 Phoenix CLI 调试 LLM 应用：获取追踪、分析错误、审查实验及查询 GraphQL API |
| [phoenix-evals](.agents/skills/phoenix-evals/)     | 使用 Phoenix 构建、运行和验证 AI/LLM 应用评估器                                                  |
| [phoenix-tracing](.agents/skills/phoenix-tracing/) | 用于追踪 LLM 应用的 OpenInference 语义约定和埋点                                        |

<a id="telemetry"></a>

### 遥测

默认情况下，Phoenix 会收集基本的 Web 分析数据（例如页面浏览量、UI 交互），帮助我们了解使用情况并改进产品。**绝不会收集任何追踪数据、评估结果或敏感信息。**

可通过设置以下环境变量停用遥测：`PHOENIX_TELEMETRY_ENABLED=false`
