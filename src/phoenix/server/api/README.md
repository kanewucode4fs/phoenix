# GraphQL API 权限矩阵

<a id="mutations"></a>

## 变更操作

| 操作 | 管理员 | 成员 |
|:---|:---:|:---:|
| 创建用户 | 是 | 否 |
| 删除用户 | 是 | 否 |
| 修改自己的密码 | 是 | 是 |
| 修改他人的密码 | 是 | 否 |
| 修改自己的用户名 | 是 | 是 |
| 修改他人的用户名 | 是 | 否 |
| 修改自己的邮箱 | 否 | 否 |
| 修改他人的邮箱 | 否 | 否 |
| 创建系统 API 密钥 | 是 | 否 |
| 删除系统 API 密钥 | 是 | 否 |
| 创建自己的用户 API 密钥 | 是 | 是 |
| 删除自己的用户 API 密钥 | 是 | 是 |
| 删除他人的用户 API 密钥 | 是 | 否 |

<a id="queries"></a>

## 查询操作

| 操作 | 管理员 | 成员 |
|:---|:---:|:---:|
| 列出所有系统 API 密钥 | 是 | 否 |
| 列出所有用户 API 密钥 | 是 | 否 |
| 列出所有用户 | 是 | 否 |
| 获取其他用户的信息，例如邮箱 | 是 | 否 |
